01Overview

Bryo turns the M-VAVE FM-1 into a four-track instrument for sculpting sound. Each track starts with a source: a tape loop, a synth, a sampler or a drum machine. The sound then goes through four effects, always in this order: GRAIN, RIPPLE, COLOR, CHRONOS. Each track also has four modulators that can move any knob, and an arpeggiator that plays the keys you hold. Four scenes per project let you jump or morph between whole sounds.

There are no menus. You hold a pad and turn a knob. I made it this way because a menu is where an idea goes to wait. If the four knobs always change the four values on the screen, your hands never have to stop and go looking for something.

Where it stands

Phases 1 to 9 of 10 are built, and it has run on a real FM-1 since 2026-10-10. Testing on the hardware is under way. bryo-status.md has the details.

02What's new

Here's what changed in the latest round of work (2026-10-13). If you used Bryo before, start here.

Two effects got new names, and grew

  • RESONATOR is now RIPPLE. It has four forms: strings, COMB, four resonant bands and a 12-band filter bank. Hold EDIT and turn SELECT to switch. It also gained a longer list of chords, DRV, RIPL (a slow drift across the pitches), and a fourth page for how the keys play it: PLCK or TUNE, PICK, STRM (strum) and VARY. More below.
  • SPACE is now CHRONOS. The echoes can age like tape (AGE), smear into a wash (DIFF) or duck under the track (DUCK). A new fifth page sets each room's TYPE (room, plate, hall or spring) and MOD.
  • RES ARP is now RIPL ARP. With RIPPLE's KEYS on TUNE, it retunes RIPPLE instead of plucking it.

New sounds

  • SYNTH has four new waves: FM (a two-operator FM synth), PD (the Casio CZ's phase distortion), VOX (a voice through three formants) and WT (a wavetable, which can be cut from any reel).
  • SYNTH's CHRD plays a whole chord from one key, on every wave.
  • POLY's TWIN gives it a second reel, mixed, split across the keys, alternated or picked at random.

Scenes

  • Each project now has four scenes. Store a sound, recall it, or morph between scenes with a knob. They live on the mixer's first EDIT page. More below.

Smaller changes

  • KEY has 15 scales now, and GRAIN can follow the project's scale.
  • Each modulator moves up to twelve knobs. The screen counts them while you hold its pad.
  • The shared tape memory is about 20 seconds (it was 28). In play, 20 seconds turned out to be plenty, and the freed RAM makes room for new features. The whole audio path now runs from fast RAM, too.
  • A muted track sleeps, so it costs nothing while it's quiet.
  • SETUP shows where the CPU goes, stage by stage. Past FACTORY in the projects there's a TEST project for comparing builds.

03Install

There's no Bryo release yet, so for now you build it yourself. Bryo keeps Felucca's update loader exactly as it was. That means installing Bryo works the same way as installing Felucca, and you can always put the FM-1 back the way it was.

1. Build the package

The build needs JieLi's toolchain, which runs on Linux x86-64 (on a Mac it runs in a linux/amd64 container), and three files from the AC79 SDK. BUILDING.md walks through the setup. Once that's done:

git clone https://github.com/thoughtgrain/moss-and-air.git
cd moss-and-air/bryo
tools/get_toolchain.sh        # installs to ~/.jieli/toolchain
./build.sh                    # makes build/bryo.fwsc

2. Install from the command line

The installer talks to the FM-1 over MIDI, so it needs two Python packages.

pip3 install mido python-rtmidi
python3 tools/fm1_install.py --info          # check which FM-1 is connected
python3 tools/fm1_install.py build/bryo.fwsc

Or use the web installer

Browsers only allow Web MIDI on a secure page, so serve a copy of the installer from localhost and open it in Chrome or Edge:

python3 web/make_site.py build/bryo.fwsc dev /tmp/bryo-site
cd /tmp/bryo-site && python3 -m http.server 8000
# open http://localhost:8000/webapp/installer/
At your own risk

Installing firmware is at your own risk. If an install fails and the FM-1 won't start, FM-1-transporter can recover it. To go back to the stock firmware, use M-VAVE's updater. Bryo's projects and tapes won't open there.

04The panel

  • Top left: MASTER (volume), SELECT (tempo), PRESETS (projects and presets), ALGORITHM (what REC records). Under them, OCT− and OCT+.
  • Top right: KNOB 1 to 4. They always change the four values on the screen.
  • Blue pads, the pages: HOME (the track's source), EDIT (GRAIN, RIPPLE), FX (COLOR, CHRONOS), GLO (the mixer and scenes).
  • Purple pads, what moves: LFO holds modulators M1 to M3, SEQ is M4 (a step sequencer), ENV is the source's own envelope, and ARP is the arpeggiator.
  • Green pads, the transport: PLAY and REC. SAVE saves, and holding it undoes. Holding SCL resets things.
  • Keys: the 16 white keys play the track. The 11 black keys above them mute tracks, flip the tape, clear things and freeze GRAIN.

05Reading the screen

Along the top you'll see the track (T1 to T4), the page's name with a dot for each of its pages, then the transport (■ stopped, ▶ playing, ● recording) and the tempo. On pages that belong to the whole project (SCENES, MASTER, KEY) the box shows the project, like P1, instead of a track. A ✱ means you have changes you haven't saved yet.

Below that are the four knobs. Each one is a little picture, a four-letter name and a value. The picture shows the value too: a dial points, a fader fills. The knob you turned last has its name inverted, so you can find your place.

The screen is white on black, and colour only tells you two things: where you are, and what's making sound. A shape or a word always says the same thing, so you never need to tell the colours apart.

ColourMeans
BlueA page of the blue pads (HOME, EDIT, FX, GLO)
PurpleA modulator's or the arpeggiator's page, or a knob a modulator moves
OrangeSound happening now: grains, strings, echoes, the playhead, the note playing
RedRecording, or the CPU close to its limit
YellowSomething to know: not saved, FROZEN, grains HELD

06First sounds

  1. Turn it on. BRYO shows for a moment, then you're on track 1's TAPE page. Don't hold OCT− and OCT+ while it starts, or you'll land in calibration.
  2. Press PLAY. You'll hear the factory scene: a drum machine that changes its own pattern, FM bells played by the arpeggiator, a drone ringing through the strings, and plucks bouncing into an echo. It's all in A minor.
  3. Turn SELECT for the tempo (40 to 240 BPM) and MASTER for the volume. Both work on every page.
  4. Press the black keys OP1 to OP4 to mute and unmute tracks 1 to 4.
  5. Hold GLO and press white key 2 to move to track 2. Almost everything you do changes the track you're on.

07Pages and modulation

Every pad opens a page. Press the same pad again and you get its next page, and after the last one it goes back to the first. To jump straight to a page, hold its pad and press a white key. While you hold the pad, one key lights up for each page.

PadPages, in order
HOMEThe source's pages (TAPE 4, SYNTH 5, POLY 5, DRUM 4). Hold it and turn SELECT to change the source.
EDITGRAIN 1 to 6, then RIPPLE 1 to 4. Hold it and turn SELECT to change RIPPLE's form.
FXCOLOR 1 to 3, then CHRONOS 1 to 5
ENVThe source's envelope (on DRUM, its KIT)
LFO, SEQA modulator's pages (LFO: M1, M2 or M3; SEQ: M4)
ARPThe arpeggiator's 2 pages, then RIPL ARP
GLOThe mixer. EDIT then steps through SCENES, CHANNEL, MASTER, KEY and SETUP.

Make a knob move

Hold LFO or SEQ and turn any knob on a source, effect or channel page. How far you turn sets how far that modulator moves the knob, from −100 to 100 %. The knob gets a purple mark so you can see it's moving.

Each modulator can move up to twelve knobs. While you hold its pad, the bottom of the screen counts them (DEPTH 1/12). If you reach twelve, turn one back to 0, or hold the pad and MONO to clear that modulator's knobs on the page.

The LFO pad holds three modulators. Hold LFO and press OP1, OP2 or OP3 to pick which one it shows. Hold LFO and turn SELECT to change what it is: an LFO, an ADSR envelope or an envelope follower. The knobs it moves stay the same. SEQ is always the step sequencer.

08Sources

Each track starts with one of four sources. Hold HOME and turn SELECT to switch. Each one keeps its own knobs, so switching back loses nothing.

TAPE

A loop in memory. The white keys play its sixteen slices. You can move where the loop starts and ends, change its speed, play it backwards or at half speed, and with SYNC on TAPE 4, lock it to a number of bars at the tempo.

SYNTH, and its new waves

A small synth with up to three voices, an envelope and a filter. Turn WAVE past the classic shapes (SIN, TRI, SQR, SAW, PLS) and SYNTH becomes something else. The first page relabels for each one:

WaveWhat it isKnobs
FMTwo sine waves, one bending the other. From a pure tone to bells, electric pianos and growls.RATI, INDX, IENV; FDBK on page 5
PDPhase distortion, the way Casio's CZ synths worked. Sounds like a filter sweep without a filter.SHAP, AMT, AENV
VOXA buzz through three formants, so it speaks vowels.VOWL, SHFT, VENV; BRTH on page 5
WTA wavetable of eight cycles. POS moves through them. The table can be built in, or cut from any reel, even your own tape.TABL, POS, PENV

Some starting points from the manual: for an electric piano, FM with RATI 1, INDX 20, IENV +60 and a short decay. For the classic CZ bass, PD with SAW, AMT 0 and AENV +80. For "ooh-wah", VOX on U with VENV +50.

CHRD (page 5, every wave) plays a chord from one key: MAJ, MIN, SUS2, SUS4, DOM7, MAJ7, MIN7, DIM, AUG, 5TH or OCT. The lowest key you hold is the root. Slide to a lower key while holding and the chord moves there without restriking.

POLY, and TWIN

POLY plays a reel, or the track's own tape, across the keys, up to four notes at once. On page 4, TWIN adds a second reel (RLB) and decides how the two play together:

  • MIX: both in every note, with BLND setting the balance. Two notes at a time in this mode.
  • XFD: low notes play A and high notes play B, crossing around middle C. BLND moves the crossing.
  • ALT: they take turns, so a repeated note doesn't sound like a machine.
  • RND: each note picks B by chance, with BLND as the chance.

TUNB tunes B against A in semitones. OFF is POLY as it was.

DRUM

Sixteen synthesized drums on the white keys, inspired by the CR-78. Pick one of ten patterns, write your own steps, or turn SEED away from 0 and it plays its own version of the pattern, with ghost notes and fills, the way a drummer would.

09Effects

Every track goes through GRAIN, RIPPLE, COLOR and CHRONOS, in that order. They all start off. Each effect's first page ends with its mix, so press EDIT or FX and turn KNOB 4 to bring one in.

GRAIN

Keeps the last few bars of the track and plays them back as small overlapping grains: stretched, held on one spot, or trailing behind with SCAN. Hold the black 0 key to freeze it, or tap to latch. Its SCAL can now be set to KEY, so the grains follow the project's scale.

RIPPLE (was RESONATOR)

The track rings through something tuned. Press EDIT seven times to reach it, then hold EDIT and turn SELECT to choose its form:

  • RIPPLE: four plucked strings, like a sitar's sympathetic strings.
  • COMB: the same lines at half length, fed back inverted. Only the odd harmonics ring, for a hollow, clarinet-like body.
  • RESO: four resonant bands on the chord's notes. DEC becomes RING and TONE becomes TILT.
  • 12-BAND: twelve bands climbing through the octaves, a filter bank that sorts whatever comes in into the chord.

Its pages, after the first (PTCH, DEC and the mix):

  • RIPPLE 2, what rings: SCAL picks the chord (HARM, MAJ, MIN, PEN, SUS2, SUS4, DOM7, MAJ7, MIN7, DIM, AUG, 5TH, OCT). TONE sets the brightness. DRV saturates the ring, so loud attacks get warm and gritty and the tail rings clean. RIPL lets the pitches drift, each a little behind the one below, like a ripple on water.
  • RIPPLE 3: a filter in front (CUT, RES, TYPE), for what of the track reaches it.
  • RIPPLE 4, the keys: KEYS on PLCK sets the root and plucks; on TUNE it only sets the root, so the track's own sound rings in that key. PICK goes from a soft mallet to a bright pick, STRM strums the strings one after another, and VARY makes each pluck a little different.

COLOR

Drive and bit crush on the first page, noise that rides the sound and a tilt EQ on the second, and what the crusher crushes on the third.

CHRONOS (was SPACE)

A delay and two shared rooms. Press FX four times to reach it.

  • CHRONOS 1: TIME, FDBK, and the two sends, DLY and VERB.
  • CHRONOS 2 and 3: which room the track sends to (A or B), the room's size, decay and pre-delay, and the tone and spread of the echoes. Room knobs are shared by every track on that room.
  • CHRONOS 4, the echoes' character: SYNC puts the delay on the tempo. AGE makes each repeat darker and more saturated, with a tape-like wow and flutter. DIFF smears each repeat into a wash. DUCK dips the echoes while the track plays and lets them swell back in the gaps.
  • CHRONOS 5, the room's character: TYPE is ROOM, PLAT (a plate, dense and bright), HALL (long and dark) or SPRG (a spring, short and twangy). MOD makes the tail waver so it sounds less metallic.

10Arpeggiators

The arpeggiator plays the keys you hold one at a time, in time with the tempo. Every track has one, and it adapts to the source:

  • SYNTH and POLY: it plays notes. With SYNTH's CHRD on, every step is a whole chord.
  • TAPE: it steps through the slices you hold.
  • DRUM: it walks through the drums you hold. Hold kick, snare and hat with UPDN and you get kick, snare, hat, snare, kick.

Try it

  1. Press ARP.
  2. Turn KNOB 1 (MODE) to KEY.
  3. Hold a chord on the white keys. You'll hear its notes one after another, a sixteenth note each. On the screen, the bars are the pattern and the filled one is playing.
KnobWhat it does
MODEOFF. KEY plays while you hold keys. LTCH keeps the last chord playing after you let go; press a new chord to replace it. ADD keeps every key you press, so the pattern grows one note at a time.
ORDRUP, DOWN, UPDN (up and back down), RND (random) or PLAY (the order you pressed them)
RNGE1, 2 or 3 octaves: the notes, then the same notes an octave up, and so on. On TAPE and DRUM it stays at 1, since a slice or a drum has no octave.
RATEHow long each step lasts: 1/4, 1/8, 8T, 1/16, 16T or 1/32 (T means triplet)
GATE (page 2)How much of each step the note sounds, from short and plucky to long
SWNG (page 2)Pushes every other step a little late

Grow a pattern

Set MODE to ADD and press keys one at a time. Each one joins the pattern and stays there. When you want to start over, hold the black POLY key on the ARP page to clear it.

RIPL ARP: an arpeggio for RIPPLE

Press ARP a third time, or hold ARP and press white key 3. This is RIPPLE's own arpeggiator, separate from the track's. Each step plays RIPPLE at a new note, whatever the track itself is playing.

  • MODE turns it on (OFF, KEY, LTCH, ADD). ORDR, RNGE and RATE work the same as above.
  • With RIPPLE's KEYS on PLCK, each step plucks the strings. On TUNE, each step retunes RIPPLE, so the track's own sound rings in the pattern.
  • With MODE on, the white keys on this page set the pattern and the track stays quiet. With MODE off, they play the track as usual.
  • Turn RIPPLE's WET up to hear it (EDIT seven times, then KNOB 4).
  • A latched or piled-up pattern keeps going after you leave the page. Hold POLY here to clear it.

How they follow the transport

Keys you hold play right away, whether the transport is running or not. A latched or piled-up pattern keeps going when you switch to another track. STOP quiets it and keeps the notes, and PLAY starts it again from the top. Each track has its own, and saving a project keeps the notes it holds. Scenes leave arpeggios alone.

11Mixer and scenes

Hold GLO for the mixer: white keys 1 to 4 pick a track, KNOB 1 to 4 set the four levels, and SELECT sets how many tracks are on (fewer tracks leave more memory for the rest). Tap GLO and the mixer stays up. Then each tap of EDIT moves through its pages:

PageWhat it does
SCENESFour sounds to recall or morph between (below)
CHANNELThe selected track's LOW, HIGH, FILT and PAN
MASTERThe master compressor: AMT, ATK, REL, MIX
KEYThe project's key and scale. 15 scales: the seven modes, harmonic and melodic minor, both pentatonics, blues, whole tone, diminished and chromatic.
SETUPHow the panel behaves (KEYS, KNOB, HOLD, LEDS), and where the CPU goes, stage by stage

Scenes

A scene is a snapshot of how the whole project sounds: every track's source, every knob that shapes its sound (the source, GRAIN, RIPPLE, COLOR, CHRONOS and the channel strip), the levels and the rooms. It leaves what's playing alone. Tapes, patterns, steps, modulation, mutes, arpeggios, the tempo and the key all stay as they are when you change scenes.

Tap GLO, then EDIT, to reach SCENES. A scene moves every track at once, so the box at the top shows the project instead of a track. The white keys 1 to 4 are the scenes (they don't play notes here), and each knob sits under its scene.

  • Store: hold a scene's white key and tap SAVE.
  • Recall: tap a scene's white key. Everything glides there in about a third of a second.
  • Morph: turn a scene's knob. Each click moves 5 % of the way toward that scene, and you can stop anywhere. Turn another scene's knob to head toward that one instead.

If a track has the same source in both scenes, its knobs glide. Settings that can't be halfway, like RIPPLE's form or a room's TYPE, switch at the midpoint. If the source changes, the track fades out, switches while it's silent, and fades back in.

The SCENES page draws a box for each scene: filled for the current one, framed for a stored one, dotted for an empty one. Under each, the letters T S P D show its tracks' sources, bright where a track would change source. Scenes are saved with the project, and the PROJECTS view shows how many each project holds before you load it. With the mixer up, you can also hold EDIT for a quick recall: SCENES shows while you hold it.

12Recording

REC records onto the track you're on. On a TAPE track it records the other three playing. That's how you bounce a scene down and keep building on it. ALGORITHM changes what each track's REC listens to: AUTO, the others, one track, or itself.

  1. Pick track 2 (hold GLO and press white key 2).
  2. Hold the black POLY key for half a second to clear its tape. The screen warns you first, and if you let go early nothing happens.
  3. Press PLAY, then REC. The header shows ● and the tape grows as it records.
  4. Press REC again after 10 to 15 seconds. Track 2 now loops what the others played.

For drum loops, hold REC and turn SELECT to record an exact number of bars. Cleared something by mistake? Hold SAVE to bring it back. The four tracks share about 20 seconds, so a long take leaves less for the others.

13Saving and undo

  • Nothing is kept until you tap SAVE. It saves everything (every knob, source, pattern, modulation, arpeggio, scene, the mixer and the tempo) into the current project, P1 to start with. A tape you recorded goes into a user reel named after it, like P1T2.
  • Hold SAVE to undo the last clear, reset or load.
  • Turn PRESETS to see the six project slots. OCT+ loads one, SAVE saves into it, holding POLY deletes it, and OCT− leaves. Pick an empty slot and press OCT+ to start a blank project. Past P6, FACTORY brings back the factory scene, and TEST is a fixed project for comparing builds.
  • Track presets (A to H, plus eight factory ones) keep one track's sound. Turn PRESETS, then press EDIT.

Saving while it plays doesn't stop the sound. If there's a new recording to write, the sound fades out for a moment and back in. Bryo prepares the next save during a quiet moment, so a save in the middle of a set stays short.

14With a computer

Files

Plug the FM-1 into a computer and it shows up as a small drive called BRYO.

  • TAPE1.WAV to TAPE4.WAV are what each track plays. Copy them off to keep them.
  • Copy a WAV on and name it TAPE2.WAV to replace track 2's tape.
  • A WAV with any other name becomes one of six user reels (up to 21.5 s). Any reel can also become a wavetable for SYNTH's WT.
  • Eject and plug back in to see new files. Deleting a file on the computer doesn't delete the sound; you do that on the REELS page.

Record what the computer plays

With the transport stopped, hold REC for a second. Set Bryo as the computer's sound output, then press REC to start a take and REC again to stop it. A take can be as long as the free memory. Trim it with STRT and LEN, set GAIN and FADE, pick a track with white keys 1 to 4, and press REC to keep it. HOME takes you back a step.

15When something goes wrong

  • A red BRYO CRASH screen: it restarts on its own after 4 seconds. Anything you hadn't saved is gone, but saved projects, reels and settings are safe. If it freezes instead, it restarts after 8 seconds. If it crashes twice within 30 seconds of turning on, it starts in update mode so you can reinstall it.
  • UPDATE MODE IN 3…: you're holding OCT− and OCT+ together. Five seconds puts it in update mode. Let go to cancel.
  • A calibration screen: OCT− and OCT+ were held while it turned on. Follow the screen, or turn it off and on again.
  • 12 DEPTHS ON M1 (or M2, M3, M4): that modulator already moves twelve knobs. Turn one back to 0, or hold its pad and MONO to clear its knobs on the page.

If you hit a crash, please write down what you were doing and open an issue. That's the quickest way for me to find the bug.

17Building and testing

You don't need the device toolchain to work on Bryo. The host tests build the whole sound chain, the controls and the screens with any C compiler, then check every screen against its pixel fingerprint. The pictures on this site come from those tests.

pip3 install Pillow fonttools
cd bryo
tests/run_tests.sh            # should end with "ALL HOST TESTS PASSED"

To see what each modulation target costs (needs numpy, and valgrind for --cost):

sh tests/mod_audit.sh --cost

On the device, load the TEST project, press PLAY, and read SETUP's load lines to see what a new build changed. bryo-architecture.md explains how each part is built, and performance-plan.md covers the recent speed work. If you'd like to help, start with CONTRIBUTING.md.
